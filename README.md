# 모니터 가리기

**만든 곳: NAPDA (냅다) · 만든 사람: Hononoo** · MIT License · v1.5

본체에 연결된 모니터만 까맣게 가리는 윈도우 프로그램이에요. PC는 그대로 돌아가고, 원격 접속(크롬 원격 데스크톱 등) 화면에는 원래 화면이 그대로 보여요.

## 다운로드

- **[최신 버전 받기](https://github.com/napdaworks/monitor-cover/releases/latest)** (GitHub 릴리스)
- 만든 곳 블로그: [호노누의 냅다AI](https://napdaworks.blogspot.com)

## 왜 만들었나

회사 PC를 원격으로 쓰는데, 자리를 비운 사이에 누가 모니터를 켜면 화면이 그대로 보였어요.
잠금(Win+L)을 걸면 원격 작업과 자동화도 같이 멈추고, 모니터만 끄면 누가 다시 켜면 끝이에요.
그래서 **PC와 원격은 그대로 두고, 본체 모니터에만 검은 화면**이 나오게 만들었어요.

## 기능

- 본체 모니터만 검은 화면으로 가리기. 원격 화면에는 원래 화면이 보이고, 클릭과 자동화도 그대로 동작해요
- 큰 버튼 하나로 쓰는 창. 트레이를 몰라도 쓸 수 있어요
- 가리기/보이기 전환: 창 버튼, 단축키, 바탕화면 버튼
- **해제 방식을 사람마다 다르게**: 단축키를 직접 눌러서 정하고, 원하면 비밀번호도 걸 수 있어요
- 본체 모니터 전원 상태 표시: 모니터에 DDC/CI로 물어봐서, 켜져 있으면 빨간 점으로 알려 줘요
- 윈도우 시작 시 자동 실행
- 설치 없음, 관리자 권한 필요 없음, exe 파일 하나

## 쓰는 법

1. `모니터 가리기.exe`를 아무 폴더에 두고 더블클릭해요. **모니터 가리기 창**이 뜨고, 바탕화면에 **모니터 가리기** 버튼이 만들어져요.
2. 창에서 큰 **[화면 가리기]** 버튼을 누르면 본체 모니터가 까매져요. 원격 화면에는 그대로 보여요.
3. 다시 보려면 창에 적힌 방법을 쓰면 돼요.
   - 키보드 단축키 (처음에는 **Ctrl+Alt+B**)
   - 원격에서는 창의 **[화면 보이기]** 버튼이나 바탕화면 **모니터 가리기** 아이콘 더블클릭
4. 창의 X를 누르면 **[창만 닫기 (계속 실행)]**와 **[모니터 가리기 끝내기]** 중에서 고를 수 있어요.
   창만 닫으면 화면 오른쪽 아래 시계 옆에 모니터 가리기 아이콘이 남아요. 안 보이면 `^`를 먼저 누르세요. 아이콘을 누르거나 `모니터 가리기.exe`를 다시 실행하면 창이 다시 열려요.

트레이 아이콘을 오른쪽 클릭하면 메뉴도 있어요.

| 메뉴 | 하는 일 |
|---|---|
| 모니터 가리기 창 열기 | 창을 다시 띄워요 |
| 본체 모니터: 켜짐/꺼짐 | 누르면 모니터별 자세한 상태가 나와요 |
| 화면 가리기 / 보이기 | 창 버튼과 같아요 |
| 해제 방식 설정... | 단축키를 바꾸고, 비밀번호를 걸거나 없애요 |
| 실행하면 바로 가리기 | 프로그램이 켜지자마자 가려요 (아래 주의 참고) |
| 윈도우 시작 시 자동 실행 | 시작프로그램 폴더에 바로가기를 만들어요. 로그인할 때는 창 없이 조용히 켜져요 |
| 바탕화면 버튼 만들기 | 바탕화면 버튼을 지웠을 때 다시 만들어요 |
| 모니터 가리기 - NAPDA by Hononoo | 만든 곳·만든 사람과 라이선스 정보 |

## 해제 방식 (단축키 · 비밀번호)

기본 단축키 Ctrl+Alt+B는 이 글을 본 사람이면 누구나 알 수 있어요. 그래서 **각자 다른 조합으로 바꿔 쓰는 걸 권해요.**

- **단축키**: [해제 방식 설정]에서 칸을 누르고, 원하는 조합(예: Ctrl+Shift+F9)을 그대로 누르면 돼요.
- **비밀번호**: "화면을 다시 보이게 할 때 비밀번호 묻기"를 켜면, 가린 화면을 풀 때 검은 화면 위에 입력 창이 떠요.
  - 5번 틀리면 30초 동안 입력할 수 없어요.
  - 비밀번호는 그대로 저장하지 않고 해시(PBKDF2)로만 저장해요.

### 잊어버렸을 때

**PC를 재부팅하세요.** 재부팅하면 화면이 보이는 상태로 시작하니, 해제 방식 설정에서 다시 정하면 돼요.
단, "실행하면 바로 가리기"를 켜 두면 재부팅해도 가려진 채로 시작해요. 이때는 원격으로 접속해서 풀어야 해요.

## 지원 환경

| 환경 | 동작 |
|---|---|
| 윈도우 11, 윈도우 10 2004 이상 | 모든 기능 (검은 화면 + 원격에선 그대로) |
| 윈도우 7 SP1, 8, 8.1, 윈도우 10 1909 이하 | 대체 모드: 검은 화면 대신 **모니터 전원을 DDC/CI로 꺼서** 가려요. 누가 모니터를 켜면 몇 초 안에 다시 꺼요 |
| .NET Framework | 4.0 이상. 윈도우 8 이상은 기본으로 들어 있고, 윈도우 7은 윈도우 업데이트로 보통 설치돼 있어요 |
| 32비트 / 64비트 / ARM | exe 하나로 모두 돼요 |
| 관리자 권한 · 설치 | 필요 없어요 |

**대체 모드에 대해 솔직하게**: 모니터가 DDC/CI 전원 끄기 명령을 따라야만 돼요. 이 명령을 무시하는 모니터가 많아요. 개발에 쓴 모니터도 상태 확인은 되는데 끄기 명령은 무시했어요.
그래서 끄기 명령을 보낸 뒤 4초 뒤에 실제로 꺼졌는지 확인하고, 안 꺼졌으면 "가리지 못했어요"라고 알려 줘요. 가리지도 못했는데 가린 척하지는 않아요.
실제 윈도우 7·8.1 PC에서는 아직 시험해 보지 못했어요.

## 회사 PC에서 쓸 때

보안이 강한 회사 PC에서도 최대한 막히지 않게 만들었어요.

- 설정과 오류 기록은 `%APPDATA%\NAPDA\MonitorCover`에 저장해요. 문서·바탕화면 쓰기를 막는 보안 설정(제어된 폴더 액세스)에 걸리지 않아요.
- 자동 실행은 레지스트리 대신 시작프로그램 폴더 바로가기를 써요. 사용자가 직접 보고 지울 수 있어요.
- 바로가기는 윈도우 셸 기능으로 직접 만들어요. 스크립트 호스트(WScript)를 막아 둔 PC에서도 돼요.
- 예상 못 한 오류가 나도 조용히 꺼지지 않고 `error.log`에 기록을 남겨요.

막힐 수 있는 경우도 있어요.

- 코드 서명이 없는 exe라서, 인터넷에서 받으면 "Windows의 PC 보호" 창이 떠요. **추가 정보 → 실행**을 누르면 돼요.
- 회사가 서명 안 된 프로그램 실행을 막아 두었다면(AppLocker 등) IT 담당자의 승인이 필요해요.

## 알아 둘 점

- 화면만 가리고 **키보드·마우스는 막지 않아요.** 원격 조작과 자동화가 그대로 돌아가야 해서예요. 그래서 누가 본체에서 Alt+Tab이나 Win+Tab을 누르면 창 미리보기가 보일 수 있어요.
- 윈도우 알림 팝업(메신저, 메일 등)은 검은 화면 위로 뜰 수 있어요.
- 화면을 가리는 도구예요. 보안 잠금이 필요하면 Win+L을 쓰세요.
- 윈도우는 로그인하고 몇 초 뒤에 시작 프로그램을 실행해요. 그래서 "실행하면 바로 가리기"를 켜 둬도 로그인 직후 몇 초는 화면이 보일 수 있어요.

## 명령줄 (자동화 스크립트에서 쓸 때)

```
"모니터 가리기.exe"            창 열기 (이미 실행 중이면 그 창을 앞으로)
"모니터 가리기.exe" --on       가리기
"모니터 가리기.exe" --off      보이기 (비밀번호가 걸려 있으면 입력 창이 떠요)
"모니터 가리기.exe" --toggle   전환 (바탕화면 버튼이 쓰는 방식)
"모니터 가리기.exe" --quit     끝내기 (비밀번호가 걸려 있으면 입력 창이 떠요)
"모니터 가리기.exe" --startup  창 없이 트레이에서 시작 (자동 실행이 쓰는 방식)
"모니터 가리기.exe" --probe-monitors 결과.txt   모니터 전원 상태 진단
"모니터 가리기.exe" --selftest 결과.txt         자가 테스트
```

## 직접 빌드하기

`build.bat`을 실행하면 돼요. 윈도우에 기본으로 깔린 C# 컴파일러(.NET Framework csc.exe)를 쓰기 때문에 따로 설치할 건 없어요.

| 파일 | 내용 |
|---|---|
| `MonitorCover.cs` | 프로그램 소스 전체 |
| `build.bat` | 빌드 스크립트 |
| `release.rsp` | 한글 exe 이름(`모니터 가리기.exe`)을 컴파일러에 넘기는 설정 |
| `app.ico` | 빌드할 때 프로그램이 직접 그리는 아이콘 (저장소에는 없고 빌드하면 생겨요) |
